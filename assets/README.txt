ASSETS FOLDER
=============
Place your application icon here before building:

  icon.ico   — Windows icon (256x256 recommended, multi-size ICO)
  icon.png   — PNG fallback (512x512 recommended)

You can convert a PNG to ICO using:
  - https://www.icoconverter.com/
  - ImageMagick: magick icon.png -resize 256x256 icon.ico

Without an icon, electron-builder will use a default Electron icon.
